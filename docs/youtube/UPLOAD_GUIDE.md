# DawnPatch YouTube upload package

## Upload files

- Video: ../demo/DawnPatch-SketchWild-1080p-synced.mp4
- Thumbnail: DawnPatch-YouTube-Thumbnail.png (1672 × 941 pixels; 1.63 MB PNG).
- Title: TITLE.txt
- Full description, including chapters: DESCRIPTION.txt
- Tags for Show more → Tags: TAGS.txt
- Optional pinned comment: PINNED_COMMENT.txt

## Suggested upload fields

- Category: Science & Technology.
- Video language: English.
- Intended audience: general developer audience; not made for kids.
- Visibility: Public for discoverability, or Unlisted for a link-accessible challenge demo.
- Keep the project repository MIT license separate from the YouTube video license field.
- After upload, paste the resulting watch URL into UPLOAD_PUBLIC_VIDEO_URL in post.md.

The thumbnail was generated with the built-in image-generation tool, using the actual verification screenshot as a reference. It is promotional artwork, not an additional test-evidence screenshot. The exact generation prompt is in THUMBNAIL_PROMPT.md.
